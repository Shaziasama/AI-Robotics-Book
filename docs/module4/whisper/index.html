Voice-to-Action: Using OpenAI Whisper for Voice Commands

Introduction to Vision-Language-Action (VLA)​

The frontier of AI and robotics is moving towards systems that can understand and act upon natural language commands in the physical world. This paradigm is often referred to as Vision-Language-Action (VLA). VLA systems integrate visual perception, language understanding, and robotic control to enable more intuitive and versatile human-robot collaboration.

This module will delve into building such capabilities, starting with voice command processing. For humanoid robots, enabling voice commands dramatically improves usability and allows for natural interaction, empowering users to direct complex behaviors without intricate programming.

OpenAI Whisper: Speech-to-Text for Robotics​

OpenAI Whisper is a general-purpose speech-to-text model. It is trained on a large dataset of diverse audio and is capable of transcribing speech in multiple languages, as well as translating those languages into English. Its robustness and high accuracy make it an excellent candidate for processing voice commands in robotics applications.

Why Whisper for Robotics?​

  • High Accuracy: Whisper performs well even in noisy environments, which is common in real-world robot operation.
  • Multilingual Support: Can understand commands in various languages.
  • Open Source: Provides flexibility for integration and customization.
  • Flexibility: Can be run locally (on a capable GPU) or via API, offering options for edge computing or cloud-based processing.

Setting Up Whisper for ROS 2 Voice Commands​

We will set up a ROS 2 node that uses OpenAI Whisper to transcribe spoken commands into text, which can then be processed by other ROS 2 nodes.

Prerequisites​

  • A working ROS 2 installation (e.g., Humble or Iron).
  • Python 3.8+ with pip.
  • A microphone connected to your system.
  • OpenAI Whisper installed: pip install -U openai-whisper
  • PyAudio for microphone access: pip install PyAudio (you might need portaudio19-dev on Linux: sudo apt-get install portaudio19-dev).
  • sounddevice (often works better than PyAudio for some systems): pip install sounddevice numpy

1. Create a ROS 2 Package for Whisper Integration​

mkdir -p whisper_ws/src
cd whisper_ws/src
ros2 pkg create --build-type ament_python whisper_voice_commander
cd ../..
colcon build
source install/setup.bash

2. Implement the Whisper ROS 2 Node (whisper_node.py)​

This node will listen to the microphone, transcribe the audio using Whisper, and publish the transcribed text as a ROS 2 String message.

Create whisper_voice_commander/whisper_voice_commander/whisper_node.py:

import rclpy
from rclpy.node import Node
from std_msgs.msg import String
import whisper
import pyaudio
import wave
import numpy as np
import time

# --- Configuration ---
AUDIO_FORMAT = pyaudio.paInt16
CHANNELS = 1
RATE = 16000 # Sample rate, Hz (Whisper model expects 16kHz)
CHUNK = 1024 # Record in chunks of 1024 samples
RECORD_SECONDS = 3 # Record for 3 seconds
WHISPER_MODEL = "base.en" # "tiny.en", "base.en", "small.en", "medium.en" etc.
OUTPUT_TOPIC = "/voice_commands"
# --- End Configuration ---

class WhisperVoiceCommander(Node):
    def __init__(self):
        super().__init__('whisper_voice_commander')
        self.publisher_ = self.create_publisher(String, OUTPUT_TOPIC, 10)
        self.get_logger().info(f'Whisper node started, publishing to {OUTPUT_TOPIC}.')
        
        self.audio = pyaudio.PyAudio()
        self.stream = None
        self.frames = []
        self.recording = False

        try:
            self.model = whisper.load_model(WHISPER_MODEL)
            self.get_logger().info(f"Whisper model '{WHISPER_MODEL}' loaded successfully.")
        except Exception as e:
            self.get_logger().error(f"Failed to load Whisper model: {e}")
            self.destroy_node()
            return

        self.get_logger().info("Say something after 'Recording started...'")

        # Create a timer to periodically check for voice input or trigger recording
        self.create_timer(1.0, self.timer_callback) # Check every second

    def start_recording(self):
        if not self.recording:
            self.get_logger().info("Recording started... Speak now!")
            self.frames = []
            self.stream = self.audio.open(format=AUDIO_FORMAT,
                                        channels=CHANNELS,
                                        rate=RATE,
                                        input=True,
                                        frames_per_buffer=CHUNK)
            self.recording = True
            self.start_time = time.time()

    def stop_recording(self):
        if self.recording:
            self.get_logger().info("Recording stopped. Processing audio...")
            self.recording = False
            self.stream.stop_stream()
            self.stream.close()

            # Process audio
            audio_data = np.frombuffer(b''.join(self.frames), dtype=np.int16).flatten().astype(np.float32) / 32768.0
            
            # Transcribe using Whisper
            try:
                result = self.model.transcribe(audio_data, language="en", fp16=False) # fp16=False for CPU or older GPUs
                transcribed_text = result["text"].strip()
                if transcribed_text:
                    self.get_logger().info(f"Transcribed: '{transcribed_text}'")
                    msg = String()
                    msg.data = transcribed_text
                    self.publisher_.publish(msg)
                else:
                    self.get_logger().warn("No speech detected or transcribed.")
            except Exception as e:
                self.get_logger().error(f"Error during transcription: {e}")

    def timer_callback(self):
        if self.recording:
            if time.time() - self.start_time > RECORD_SECONDS:
                self.stop_recording()
        else:
            # Simple trigger: Start recording if not recording and nothing's happening
            # In a real app, this would be button press, voice activity detection, etc.
            self.start_recording() # For this example, just continuously record/process

    def __del__(self):
        if self.audio:
            self.audio.terminate()

def main(args=None):
    rclpy.init(args=args)
    node = WhisperVoiceCommander()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

Update whisper_voice_commander/setup.py in the entry_points section:

'console_scripts': [
    'whisper_node = whisper_voice_commander.whisper_node:main',
],

3. Build and Run​

cd whisper_ws
colcon build
source install/setup.bash

# In one terminal
ros2 run whisper_voice_commander whisper_node

# In another terminal to listen to commands
ros2 topic echo /voice_commands

Speak into your microphone when "Recording started..." appears. You should see your transcribed speech echoed in the second terminal.

Optimizing Whisper

For faster transcription on systems with GPUs, ensure CUDA is properly installed and fp16=True can be used in model.transcribe(). For embedded systems or lower-power devices, consider using smaller Whisper models (tiny.en, base.en).

Exercise: Filtering Voice Commands​

Modify the WhisperVoiceCommander node to implement basic command filtering. For instance, only publish commands that start with a specific "wake word" (e.g., "Robot, move forward") or belong to a predefined set of actions. You could also add a confidence score threshold for transcription. This helps prevent misinterpretations and unintended robot actions.

Conclusion​

Integrating OpenAI Whisper with ROS 2 provides a robust foundation for building voice-controlled humanoid robots. By accurately transcribing spoken commands, we enable a more natural and intuitive mode of interaction. This speech-to-text capability is a critical first step in the Vision-Language-Action pipeline. In the next chapter, we will connect these voice commands to cognitive planning systems using Large Language Models to translate natural language into concrete robot actions.
