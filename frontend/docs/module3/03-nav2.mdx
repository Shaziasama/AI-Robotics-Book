## Introduction to ROS 2 Navigation Stack (Nav2)

The ROS 2 Navigation Stack (Nav2) is a powerful framework for enabling robots to autonomously navigate complex environments. It provides a complete suite of tools for localization, path planning, obstacle avoidance, and motion control. While primarily designed for wheeled robots, its modular architecture allows for adaptation to other robot types, including bipedal humanoids, with careful consideration.

### Key Components of Nav2

Nav2 consists of several interconnected nodes that work together:
*   **map_server**: Provides the static map of the environment.
*   **amcl (Adaptive Monte Carlo Localization)**: Estimates the robot's pose within a known map.
*   **planner_server**: Implements global path planning algorithms (e.g., A*, Dijkstra, RRT*).
*   **controller_server**: Implements local path planning and obstacle avoidance algorithms (e.g., DWA, TEB).
*   **bt_navigator (Behavior Tree Navigator)**: Orchestrates the overall navigation behavior using behavior trees.
*   **smoother_server**: Smooths generated paths.
*   **waypoint_follower**: Allows the robot to follow a sequence of waypoints.
*   **recovery_server**: Handles recovery behaviors when navigation gets stuck.

## Adapting Nav2 for Bipedal Humanoid Movement

Traditional Nav2 planners assume differential drive or holonomic wheeled robots. Bipedal humanoids, with their unique locomotion constraints (e.g., zero moment point control, step planning, balance maintenance), require a more specialized approach.

### Challenges for Humanoids in Nav2

*   **Locomotion Model:** Humanoids move by walking, which is fundamentally different from wheel-based motion.
*   **Stability:** Maintaining balance is paramount; dynamic instability can lead to falls.
*   **Footstep Planning:** Navigation often involves planning individual footsteps rather than continuous velocity commands.
*   **Height Variation:** Humanoids can step over obstacles or climb stairs, requiring 3D navigation.
*   **Dynamic Reconfiguration:** Leg configurations change during walking, affecting the robot's kinematics and footprint.

### Approaches to Integrate Humanoids with Nav2

1.  **Velocity Command Abstraction:**
    *   Treat the humanoid's walking controller as a "black box" that accepts high-level velocity commands (linear x, angular z) and translates them into appropriate footstep and joint commands.
    *   Nav2 outputs `geometry_msgs/Twist` messages to a custom `humanoid_cmd_vel_converter` node.
    *   This converter node then calls the humanoid's walking engine.

2.  **Custom Controller Plugins:**
    *   Develop custom `controller_server` plugins for Nav2 that are specifically designed for bipedal locomotion. These plugins would understand the humanoid's dynamics and generate footstep plans or joint trajectories directly.

3.  **Footstep Planning as a Global Planner:**
    *   Replace or augment the global planner with a dedicated footstep planner that considers stability and terrain traversability.

## Tutorial: Abstracting Humanoid Walking for Nav2

Let's assume we have a basic humanoid walking controller (a ROS 2 node) that can receive `geometry_msgs/Twist` commands and make the robot walk. We'll set up a minimal Nav2 configuration.

### Prerequisites

*   A Gazebo simulation of your humanoid (from Module 2).
*   A dummy `humanoid_walking_controller` ROS 2 node that subscribes to `/cmd_vel` and prints received commands. (In a real scenario, this would trigger actual walking motions).
*   Nav2 packages installed (`ros-<distro>-navigation2`, `ros-<distro>-nav2-bringup`).

### 1. Create a Dummy Humanoid Walking Controller

Create `my_humanoid_ws/src/humanoid_control/humanoid_control/humanoid_walking_controller.py`:

```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist

class HumanoidWalkingController(Node):
    def __init__(self):
        super().__init__('humanoid_walking_controller')
        self.subscription = self.create_subscription(
            Twist,
            'cmd_vel',
            self.cmd_vel_callback,
            10)
        self.subscription  # prevent unused variable warning
        self.get_logger().info('Humanoid walking controller started. Waiting for /cmd_vel...')

    def cmd_vel_callback(self, msg):
        linear_x = msg.linear.x
        angular_z = msg.angular.z
        self.get_logger().info(f'Received /cmd_vel: Linear.x={linear_x:.2f}, Angular.z={angular_z:.2f}')
        # In a real controller, this would translate to complex walking patterns
        if linear_x > 0.1:
            self.get_logger().info("Humanoid is walking forward!")
        elif linear_x < -0.1:
            self.get_logger().info("Humanoid is walking backward!")
        elif angular_z > 0.1:
            self.get_logger().info("Humanoid is turning left!")
        elif angular_z < -0.1:
            self.get_logger().info("Humanoid is turning right!")
        else:
            self.get_logger().info("Humanoid is standing still.")

def main(args=None):
    rclpy.init(args=args)
    humanoid_walking_controller = HumanoidWalkingController()
    rclpy.spin(humanoid_walking_controller)
    humanoid_walking_controller.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

Update `my_humanoid_ws/src/humanoid_control/setup.py` `entry_points`:

```python
'console_scripts': [
    'humanoid_walking_controller = humanoid_control.humanoid_walking_controller:main',
],
```

### 2. Basic Nav2 Configuration

We need a basic map and Nav2 parameters.

*   **Create a simple map**: Use `map_saver` in Gazebo.
    1.  Launch your Gazebo world with some obstacles.
    2.  Use a teleop node (e.g., `turtlebot3_teleop`) to drive a robot around to generate a map via Gmapping or Cartographer.
    3.  Save the map: `ros2 run nav2_map_server map_saver_cli -f my_map`. This will create `my_map.yaml` and `my_map.pgm`.

### 3. Create a Nav2 Launch File for Humanoids

Create `my_humanoid_ws/src/humanoid_bringup/launch/nav2_humanoid_bringup.launch.py`:

```python
import os
from ament_index_python.packages import get_package_share_directory
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, IncludeLaunchDescription, GroupAction
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration, PythonExpression
from launch_ros.actions import Node
from nav2_common.launch import RewrittenYaml

def generate_launch_description():
    humanoid_bringup_pkg = get_package_share_directory('humanoid_bringup')
    nav2_bringup_pkg = get_package_share_directory('nav2_bringup')

    # Arguments
    use_sim_time = LaunchConfiguration('use_sim_time', default='true')
    map_yaml_file = LaunchConfiguration('map', default=os.path.join(humanoid_bringup_pkg, 'maps', 'my_map.yaml'))
    params_file = LaunchConfiguration('params_file', default=os.path.join(humanoid_bringup_pkg, 'config', 'nav2_humanoid_params.yaml'))

    # Rewrite params file for current context
    configured_params = RewrittenYaml(
        source_file=params_file,
        root_key='',
        param_rewrites={},
        convert_expressions=True,
    )

    # Launch Nav2
    nav2_launch_cmd = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(os.path.join(nav2_bringup_pkg, 'launch', 'bringup_launch.py')),
        launch_arguments={
            'map': map_yaml_file,
            'use_sim_time': use_sim_time,
            'params_file': configured_params,
        }.items(),
    )

    # Humanoid Walking Controller
    humanoid_controller_node = Node(
        package='humanoid_control',
        executable='humanoid_walking_controller',
        name='humanoid_walking_controller',
        output='screen',
        parameters=[{'use_sim_time': use_sim_time}],
    )

    return LaunchDescription([
        DeclareLaunchArgument(
            'use_sim_time',
            default_value='true',
            description='Use simulation (Gazebo) clock if true'),
        DeclareLaunchArgument(
            'map',
            default_value=map_yaml_file.perform(None),
            description='Full path to map yaml file to load'),
        DeclareLaunchArgument(
            'params_file',
            default_value=params_file.perform(None),
            description='Full path to the ROS2 parameters file to use for all launched nodes'),
        humanoid_controller_node,
        nav2_launch_cmd,
    ])
```
